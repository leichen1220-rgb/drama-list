# 我的劇單

GitHub Pages + Supabase 個人劇單。

## v6.7 更新
- 新增「觀後感」，與備註分開儲存。
- 已看完且有觀後感時，卡片／精簡模式於「編輯」旁顯示 ▸ 觀後感，預設收合。
- 觀後感內容包含於 Excel 匯出及 JSON 系統備份。
- 不刪除既有觀看資料。

## 更新步驟
1. 先在 Supabase SQL Editor 執行 `migration-v6.7.sql`，新增 `review` 欄位。此指令可重複執行。
2. 將更新包的網站檔案上傳到 GitHub Pages 專案根目錄，覆蓋同名檔案。
3. 等 GitHub Pages 部署完成，重新整理頁面，確認顯示 v6.7。

## 既有功能
- 多種檢視、搜尋、篩選、批次修改、雲端同步。
- Excel 匯出、JSON 系統備份。
- 觀看日期、進度、播出狀態與同看欄位。
