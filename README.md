# 我的劇單 v6.4

更新重點：
- 顯示版本號 v6.4。
- 新增手動「↻ 同步」；App 從背景回前景時也會自動同步。
- 手機篩選改成單欄滿版、chips 換行，底部固定「清除篩選／套用」。
- OTT 正式欄位改為「同看」（是／否／未設定）；舊 OTT 由 migration.sql 搬到備註。
- 新增「看完日期」；勾選已看完或按「看完」時，空白日期會預設今天，可手動修改；取消勾選不會自動清掉日期。
- 新增「最近看完」排序。
- 工具列移除「還原備份／合併此裝置舊資料」，「備份資料」改名「系統備份」。
- 重複整理改成自訂確認視窗與進度顯示。
- Excel 匯出欄位更新為：看完、國、類別、名稱、季、集數、目前觀看、首播年、狀態、系列作品、備註、同看、加入日期、看完日期、重複排除公式。

## 更新順序（重要）
1. 先到 Supabase SQL Editor 執行 `migration.sql`。
2. 再把 `index.html`、`sw.js`、`manifest.webmanifest`、`drama-list-template.xlsx`（以及 data.js 若 repo 原本有）上傳到 GitHub repo 根目錄覆蓋舊檔。
3. GitHub Pages 部署完成後，頁面標題旁應顯示 `v6.4`。若仍看到舊版，關閉頁面後重開一次。

`migration.sql` 不會替舊的「已看完」資料亂補看完日期；舊資料的 finished_date 會維持空白。
