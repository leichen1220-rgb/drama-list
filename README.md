# 我的劇單

GitHub Pages + Supabase 個人劇單。

## v6.8 更新
- 排序選單新增「最近更新」，依 `updated_at` 由新到舊排序；觀看進度、觀後感、備註等編輯都算更新。
- 表格模式新增「最後更新」欄，卡片及精簡模式不顯示。
- `updated_at` 缺失時，已看完作品以看完日期作備援，再退回建立時間；不修改既有資料庫時間。
- 沿用現有 `dramas_set_updated_at` 觸發器，不需要新增 SQL。

## 更新步驟
1. 把 `index.html`、`sw.js`、`README.md` 上傳 GitHub 專案根目錄，覆蓋同名檔案。
2. 等 GitHub Pages 部署後重新整理，確認版本顯示 v6.8。
3. 在排序選單選「最近更新」測試。無需重新匯入資料或執行 SQL。

## 既有功能
- 觀後感、搜尋、篩選、批次修改、雲端同步。
- Excel 匯出、JSON 系統備份。
- 觀看日期、進度、播出狀態、同看欄位。
